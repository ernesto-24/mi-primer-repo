# Agenda de contactos

Proyecto de práctica de Git.

## Cómo usar

Cada archivo de la agenda tiene una función:

- `contactos.txt`: lista de contactos con nombre, teléfono y correo.
- `tareas.txt`: lista de tareas pendientes.
- `compras.txt`: lista de compras.
- `.gitignore`: archivos que Git no debe guardar, como `secretos.txt`.

Para agregar un contacto, escribe una línea nueva en `contactos.txt` con el formato `Nombre - teléfono - correo`.
